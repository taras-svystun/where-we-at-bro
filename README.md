# where-we-at-bro

A concierge over all my projects. It reads them and never changes them.

## Start

```sh
cd ~/Documents/Projects/where-we-at-bro && vs .
```

Then open a Claude tab in VS Code and type a command.

## Commands

| Command | What it does | Example |
|---|---|---|
| `/status` | Table of all projects, the 2 that matter now, and where my priorities and the facts disagree. | `/status` |
| `/find <what>` | Finds the project or session where something was done. | `/find local AI on the phone` |
| `/next <project>` | Gives the line to open that project and a prompt for its next step. | `/next fluent` |

Not built yet: all three are in `docs/PLAN.md`, steps 3 to 5.
